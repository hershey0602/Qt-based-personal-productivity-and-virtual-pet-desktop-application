1. `pet_buding_lv1.png` 和七个主导航 SVG 原样提取自本次用户提供的 HTML。没有查找或复用其他会话文件。输入素材的权利沿用原始来源；本包没有用户未提供的第三方授权证明。
2. `pet_buding_lv2.png`、`pet_buding_lv3.png` 是以本次布丁原图为参考生成的等级变体；未引入其他品牌角色、外部图库或照片。两图保留透明背景、抱胡萝卜姿态，分别用叶芽和花冠区分。

4. 本包不包含第三方歌曲、商业字体或 Qt 二进制。字体采用系统回退，不将微软字体文件打包。下一阶段由部署者记录所选 Qt、编译器、多媒体后端和字体的实际许可文件。
5. HTML 内的平台 Emoji 仅为原型显示；Qt使用明确列出的SVG/PNG文件。ASSET_MANIFEST记录各文件SHA256，避免资源被悄悄换掉。
