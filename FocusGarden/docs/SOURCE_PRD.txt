产品需求、完整交互流程与页面跳转说明书（PRD V2.0）
文档状态：小组评审稿；确认后冻结为产品需求基线
适用对象：四人小组、Qt 界面开发 AI、业务逻辑开发 AI、测试和答辩人员
项目边界：Windows 单机离线 / Qt 6 Widgets + C++17 + SQLite / 四人 / 30 天
本版主要修订：补齐页面入口与出口、弹窗、运行状态、异常分支、跨模块同步、模块验收和旧 UI 冲突处理。
先读这个结论：本项目有 7 个主导航页面（总览、任务、专注、宠物、统计、音乐、设置）、1 个复用任务编辑弹窗、若干确认与结果提示。所有页面属于同一个主窗口。不能让 AI 因为参考图出现某个按钮就自行实现其功能。
0. 如何使用本文以及版本优先级
标记约定：P0 为一个月必须实现；不做 为明确排除；建议实现 不是第一版硬性要求。表内规则是建议由团队确认的产品决策，不是已经运行的软件事实。
1. 最容易理解的产品全流程（首次启动举例）
双击 FocusGarden.exe。程序加载本地数据库和设置，进入「总览」。首次使用时没有任务、专注时长为 0、金币为 0、宠物布丁为 Lv.1。
点总览的「新建任务」；弹出一个任务编辑框，而不是离开总览。填写标题和可选信息，点「保存」，弹窗关闭，回到总览。打开「任务」页能看到新任务。
在「任务」页点这条任务的「开始专注」；切换到「专注」页并选中任务，此时倒计时仍未开始。点大号「开始」，才进入计时。
计时中可以点击左侧「音乐」播放本地歌曲，也可以进入「统计」或「总览」；计时不中断。再次点「专注」，继续看到同一轮时间。
自然完成 25 分钟后，保存专注记录；结算成功后获得 20 金币。页面显示完成结果，总览、统计、宠物页刷新。
进入「宠物」点击「喂食」，确认有 15 金币后扣除 15、EXP 增加 10、心情增加 15；宠物等级满足门槛时显示静态升级提示。
进入「设置」将默认专注调整为 50 分钟；修改立即保存。此时正在进行的会话不改变，新建下一轮才使用新默认时长。
关闭程序、重新打开：任务、完成专注记录、金币流水、宠物状态和设置都还在。播放音乐需要重新开始；本地路径可按配置恢复列表。
一句话记忆：任务可以弹窗创建；专注只能手动开始；奖励只能由真实完成触发；页面可自由切换但不重启计时；设置即时保存。

3. 主窗口与完整导航总规则
3.1 程序中到底有几个“页面”？
七个导航页面：DashboardPage / TaskPage / FocusPage / PetPage / StatisticsPage / MusicPage / SettingsPage。左侧导航固定；顶部固定显示产品名称和“本地运行”，不用用户头像、昵称或通知铃铛。窗口使用 Windows 原生最小化、最大化、关闭按钮。中间统一用 QStackedWidget 切换页面。
不是导航页面的弹窗：TaskEditDialog 新增/编辑任务；删除确认框；放弃专注确认框；退出确认框；完成反馈；错误提示；系统文件选择对话框。这些不会出现在左侧导航。
3.2 七个页面之间的完整切换矩阵
规则：只要没有打开阻止主窗口操作的模态弹窗，从任一页面均可点击左侧导航进入其他六个页面；点击当前页面仍停留当前页面。表中的“可”表示允许切换，不代表会自动开始新操作。
四条全局不变量：①切换导航不清空已有任务筛选；②切换导航不停止运行中/暂停中的专注（状态原样保持）；③切换导航不停止音乐播放；④切换导航本身不修改数据库，也不弹出要求保存的对话框。
3.3 所有“不是侧边栏”的跳转入口
没有另设“返回上一页”按钮：主导航依靠左侧导航；任务编辑弹窗的返回方式是「保存/取消/关闭」，不是历史后退。
3.4 弹窗、页面离开、程序退出的统一约定
模态弹窗打开时：不能点击背景导航切页。保存成功/确认成功才自动关闭；校验失败或数据库失败则保持打开。
新建/编辑有未保存内容时点取消、右上角 X 或 Esc：若内容未改动则直接关闭；如已修改，则弹出「放弃未保存的修改？」确认。选择继续编辑仍留在弹窗。
TaskPage 搜索/筛选：在本次程序运行中切到别的页面后回来，保留搜索条件、筛选项和当前选中任务；重新启动软件则恢复默认筛选。
FocusPage：离开页面不改变当前状态；回来仍显示同一轮任务、模式、时间，绝不重新生成计时器。
MusicPage：离开页面播放器继续；回到页面显示真实播放状态及进度。
退出程序无活动专注：直接关闭，音乐停止；数据和设置此前已持久化。
退出程序有 RUNNING/PAUSED 专注：确认框写「当前专注尚未完成。退出将放弃本次专注，不获得金币。是否退出？」；点取消：保持程序打开及原计时状态；点退出：保存 ABANDONED 后退出。若持久化失败则阻止正常退出并显示错误，允许重试（强制结束进程无法保证保存，重启时恢复处理）。
4. 每个页面入口、控件、退出和验收（开发用）
4.1 总览 DashboardPage（A）
进入：首次启动默认页面；左侧总览。离开：任意导航或快捷按钮。数据来源：B 的任务/专注/统计接口 + C 的余额与宠物接口。
本页验收：先打开空数据库确认所有空值与空状态，再新增一条今日截止任务、勾选完成、完成一轮专注、喂食；首页对应信息无需重启就更新。
4.2 任务管理 TaskPage（B）
进入：左侧任务、总览「查看全部」。布局功能：顶部新增/搜索/筛选；中间任务列表；右侧只读详情。退出：任意左侧导航、从任务进入专注。
规则补全：任务标题去空格后 1～100 字符；备注最多 500；分类固定学习/工作/生活，优先级高/中/低；截止时间可为空且允许过去日期（用于补录任务）；已完成任务仍能编辑、删除、恢复，但其「开始专注」禁用。不存在“完成任务直接发金币”。
运行中关联任务被修改/删除时：正在进行的专注不停止、不换任务；会话开始时保存任务标题快照，历史记录使用快照。任务被完成或软删除后，已有专注照常计时和正常结算；只是以后不能再从该完成/删除任务创建新的专注。
本页验收：五类操作（新建/编辑/完成恢复/删除/搜索筛选）正常，重启后数据仍在；任务进入专注时只是预选。
4.3 任务弹窗 TaskEditDialog（B，A 提供统一外观样式）
本页验收：无效标题不会保存，数据库失败不会关闭窗口或显示“成功”；新建与编辑共用一个弹窗组件。
4.4 专注 FocusPage（B，C 负责奖励结算）
进入：左侧专注、总览「开始/快速专注」、任务行「开始专注」。离开：可切任何导航，计时状态不变。
状态与控件矩阵：
从任务页点击另一个任务时若已有活动计时：打开 FocusPage 显示当前进行中/暂停中的会话，并在顶部提示「已有一轮专注，无法切换任务。请先完成或放弃。」绝不结束或替换现有会话。当前任务在其他页被改动或删掉，现有计时继续，用开始时保存的标题快照完成历史记录。
专注结束时用户不在此页：完成处理仍由后台的 FocusEngine 触发（不是切回页面时才触发），全局出现轻提示「专注完成，奖励已到账」；返回 FocusPage 仍能查看最近一次完成结果和历史。不能要求用户待在计时页面才能得到金币。
保存与结算异常（必须讲清）：①自然结束先保存 COMPLETED 专注记录；保存失败进入 SAVE_FAILED 提示重试，禁止发金币；②保存成功后通知 C 按会话唯一 ID 结算，若结算失败，专注记录仍是完成，显示「专注已记录，金币结算待重试」，下次启动或打开专注页可重试未结算记录；③重复重试不得重复发奖。会话写入与金币写入的服务边界由 B/C 在接口文档中固定。
异常退出：若进程异常终止，下次运行时将历史遗留 RUNNING/PAUSED 状态标为 ABANDONED，不补发金币。QElapsedTimer 计算活动经过时间；QTimer 仅用于刷新显示。
本页验收：计时开始/暂停/继续/放弃/自然完成、页面切换、最小化、另一任务冲突、关闭确认、重启恢复都可演示。
4.5 宠物与奖励 PetPage（C）
进入：左侧宠物、总览「去喂养」。退出：任意导航。无任务系统依赖的直接操作：金币仅由合法专注完成记录产生；宠物不自动发金币。
特别提醒：宠物不做抚摸、购买食物、查看资料、背包、成长时间线、死亡。经验是累计值，不在每次升级后重置；达到 Lv.3 后仍可喂食、获得 EXP 并改善心情，但无 Lv.4 和虚假的升级进度条。
本页验收：0 金币点击喂食不变；20 金币喂食变 5；累计 50/150 EXP 时正确升级；重启结果保持一致。
4.6 学习统计 StatisticsPage（B）
进入：左侧统计、专注页「查看完整记录」。离开：任意导航。统计不提供编辑操作。
注意：今日专注仅计自然完成记录，正在进行的计时不提前计入；任务完成率不是「今日任务完成率」而是全量未删除任务完成率，首页也必须一致。跨午夜的专注全部记在自然结束当天。分类饼图、连续天数、数据导出不做。
本页验收：一次 25 分钟完成后，今日和累计数同步增加，历史新增一条，图表对应日期更新；放弃不增加时长。
4.7 音乐 MusicPage（D）
进入：左侧音乐、总览「播放音乐」。退出：任意导航但播放继续；关闭程序时播放停止。
首次打开：不内置歌曲，不显示虚构的 Rainy Study Session 歌单。播放列表可使用 QSettings 存储原始本地路径，但文件被移动后必须提示失效。无联网、收藏、歌词、环境音、自启播放和专注联动控制。
本页验收：导入 2～3 个本地音频文件，播放、暂停、拖动、切歌、移除、跨页保持播放、重启后的清单恢复均能操作。
4.8 极简设置 SettingsPage（D；A/B 对接）
进入：左侧「设置」。离开：任意导航。无“账户中心”或二级设置页面；只有三项可修改参数和两块只读信息。
设置无单独保存按钮：每次改动即时落盘并反馈「已保存」。若写入失败则恢复旧选项值并提示。完成提示音由本地原创短音效文件提供，避免音乐版权问题；本版不做任务到期推送和系统通知中心。Windows 自带 DPI 缩放不等于另做一个“窗口缩放”设置。
本页验收：选择默认 50 分钟，离开设置再进入专注新会话默认 50；当前活动会话仍按原计划；重启设置保持；关闭音效后下次完成不播放提示音。
5. 典型场景的“用户点击流程图（文字版）”
FLOW-01 首页创建任务
总览 → 点击「新建任务」 → TaskEditDialog（空） → 输入字段 → 点击保存 → 校验 → 成功：保存数据库/关弹窗/总览刷新；失败：留在弹窗并提示。
点击取消/X/Esc → 有未保存变更？否：直接关闭；是：询问是否放弃 → 选择继续编辑：留在弹窗 / 选择放弃：不保存并关闭。
FLOW-02 任务编辑、完成与删除
任务页 → 点某行 → 右侧详情更新；点编辑 → 同一个 TaskEditDialog（带原值） → 保存 → 列表和详情刷新；勾选任务 → 状态写入 → 页面统计更新 → 不发金币；点删除 → 二次确认 → 软删除 → 该任务从列表消失/历史不变。
FLOW-03 从任务进入专注
任务页未完成任务 → 点开始专注 → 是否有进行中/暂停中会话？
没有 → 跳 FocusPage + 预选该任务 + 进入 IDLE → 用户手动点开始 → RUNNING。
有 → 跳 FocusPage + 保留当前会话 + 弹轻提示，**不切换任务/不重启**。
FLOW-04 暂停、继续、放弃
RUNNING → 暂停 → PAUSED（时间冻结） → 继续 → RUNNING。
RUNNING 或 PAUSED → 放弃 → 确认？否：原状态不变；是：保存 ABANDONED → 不发金币 → IDLE。
FLOW-05 专注自然结束与奖励
RUNNING → 倒计时到 0 → 写入 COMPLETED → 写入成功？
否 → SAVE_FAILED + 重试保存；不能发金币。
是 → C 根据 sessionId 检查是否已结算 → 未结算则写唯一金币收入流水 → 成功：金币增加/全页刷新/显示奖励 → 失败：记录完成但提示金币待结算，下次可恢复重试。
休息倒计时结束 → 普通休息完成提示 → IDLE，不产生有效专注和金币。
FLOW-06 喂食宠物
宠物页 → 点喂食 → 读取余额 → 余额 < 15：提示不足，不扣钱。
余额 >= 15：同一事务插入 -15 金币流水并更新宠物 EXP/心情 → 成功：刷新等级/余额和首页 → 失败：事务回滚并提示。
FLOW-07 修改设置
任意页面 → 左侧设置 → 修改默认专注 25→50 → 本地保存 → 提示已保存 → 返回专注 → 新建下一轮使用 50 分钟。
正在计时中的专注继续按照原来的 25 分钟运行，不发生即时重置。
FLOW-08 播放本地音乐
任意页 → 音乐 → 空列表 → 添加本地音频 → 列表出现 → 选择一首 → 点击播放 → 切换任务/宠物/统计页，音乐继续 → 返回音乐仍显示播放状态 → 关闭应用时音乐停止。
FLOW-09 关闭程序
点击窗口关闭 → 是否存在 RUNNING/PAUSED 专注？否：直接退出；是：弹确认。
选择取消 → 留在应用，计时状态不变。
选择退出 → 标记 ABANDONED、不发金币 → 退出；保存失败则提示、允许重试，不能谎称已保存。
6. 专注与音乐状态不会被页面切换重置
7. 系统数据由谁写、谁读、谁刷新
一致性原则：主页、统计页只读来自同一服务的结果；不允许把设计图上的“72%”“328 金币”硬编码成真实数字。数据更新发统一信号，页面重新读取。B/C 要约定“已完成但未结算金币”的恢复流程。
8. 输入、提示、空状态和异常处理的统一语句
提示样式：成功是短时轻提示；不可逆（软删除、放弃、退出）用二次确认；需要用户解决的错误使用明显错误提示。文案由 A 统一，业务成功/失败由各负责人返回信号和错误信息。
