# 差异与实施清单

功能按 PRD V2.0；视觉按 UI V2.1。七页的黄绿奶油白配色、导航、主容器比例和卡片风格保持原样。

| 项目 | 附件现状 | 本次处理 |
|---|---|---|
| 控件坐标 | 草稿引用的 ALL_COMPONENT_GEOMETRY_1600x900.json 未随附件提供 | 提供全部组件的明确布局基线、对象名、三尺寸表和布局契约；最终 Qt 回填是下一阶段验收门槛 |
| 设置负责人 | 原PRD与旧交付将设置归A | 按用户最新分工由D负责SettingsPage与SettingsService；A维护统一UI和整合，功能规则不变 |
| Qt 工程 | 原任务要求 Starter | 按补充说明改为工程树、接口、组件树、信号槽、状态机和验收蓝图，不交付 Qt 工程 |
| 搜索 | 原PRD正文与TASK-02对搜索范围有冲突，HTML搜标题与备注 | 队长本轮明确确认仅搜索标题；有效PRD与蓝图统一，不冒称原PRD无歧义 |
| 宠物图片 | 原型只有一个内嵌 PNG，草稿明确 Lv.2/3 未完成 | 提取原布丁为 Lv.1，生成保留原角色与姿态的 Lv.2/3；分别用芽叶与花冠区分 |
| 满级进度 | HTML Lv.3 仍显示 100% 进度条 | 保留成长卡，满级显示累计 EXP 与「已满级」，隐藏升级进度条 |
| 保存失败锁定 | 部分原型入口只拦 RUNNING/PAUSED | SAVE_FAILED 与 REWARD_PENDING 也禁止覆盖原会话 |
| 奖励结算 | HTML 将记录和金币同时更新 | 蓝图明确先保存 COMPLETED，再按 sessionId 幂等结算；原型补齐待结算与重试展示 |
| 未保存编辑 | 新增、编辑共弹窗；嵌套二层确认 | 保留输入，继续编辑不重建表单；保存失败不关闭 |
| 本地音乐 | 首次为空，无内置歌单 | 保持；移除其他曲目时保持正在播放的曲目与进度 |
| 设置保存 | 原型存储异常被吞掉 | 原型补充失败反馈与恢复旧值；Qt 蓝图要求 QSettings::sync/status |
| Emoji 装饰 | 书、茶、叶子、胡萝卜依赖平台字体 | 提供相近风格可加载 SVG 替代，不改变功能和主布局 |
| 原生窗口 | HTML 有圆角外框 | Qt 采用原生标题栏，内部保留圆角壳；1600×900 指客户区 |
| Qt 滚动条 | 浏览器截图与 Qt 原生滚动条占位不同 | 表中记录 8px 滚动条占位后的可用区，差异列明确记录；禁止静默缩放控件掩盖差异 |

实施顺序：冻结ID/Token/资源与FG-API → A日1建立唯一公共壳 → B/C/D同步完整真实业务 → 日5完成全部PRD功能和持久化验收。日6后只测试、修复、视觉/性能/稳定性优化、部署和答辩；日1演示支架不代表阶段完成。实际Qt截图和几何未复测前不宣称视觉通过。

当前接口、分工与开工阶段统一升级为FG-API-1.0；前5天完成全部PRD必做功能，日1支架不能作为日5验收。原参数表“业务接口”列只作行为索引，准确签名见唯一API契约。
